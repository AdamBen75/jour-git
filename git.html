Tableau des commandes Git

Commande Description
git init Initialise un nouveau dépôt Git
git status Affiche l’état du dépôt
git add . Ajoute tous les fichiers modifiés au staging
git commit -m "message" Crée un commit avec un message
git push Envoie les commits sur GitHub
git pull Récupère et fusionne les changements distants
git clone URL Clone un dépôt distant
git branch Liste les branches
git checkout branche Change de branche
git merge branche Fusionne une branche dans la branche courante
